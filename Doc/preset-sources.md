# 公開プリセットの出典と移植範囲

2026-11-12に公開ファイルを確認し、前回の仮設計曲線を置き換えた。どちらも作者による音再現用設定であり、メーカーの設計仕様・実車との完全一致を意味しない。

## JR「墜落」：E231系 日立

出典: [VvvfGeeks/YAML-Files / JRE_E231_HITACHI.yaml](https://github.com/VvvfGeeks/YAML-Files/blob/2f83dc2cd0466b35ce9720d5101164656064f70c/VVVF/JRE_E231_HITACHI.yaml)。コミット`2f83dc2cd0466b35ce9720d5101164656064f70c`。数値の抜粋と元ファイルのSHA-256は[preset-sources.json](preset-sources.json)へ保存。

### 力行

| 基本波f1 Hz | 公開設定と移植内容 |
|---:|---|
| 0～23 | 非同期、fc=1045 Hz |
| 23～49 | 非同期、(f1,fc)=(23,1045)→(48.9,710)の直線 |
| 49～60 | 非同期、(49,710)→(60,1750)の直線 |
| 60～67 | 広域3パルス、公開設定SYNC3 Alt1に対応する直接スイッチング角 |
| 67以上 | 1パルス矩形波 |

元データの下降直線の終点は48.9 Hz、次のバンド開始は49 Hzで別の値。元シミュレーターの比例式はクランプせず外挿するため、48.9～49 Hzも同じ直線を使い、49 Hzで710 Hzへ切り替える。単に23～49で1045→710と補間する実装にはしていない。

### 減速・回生用の音パターン

| 基本波f1 Hz | 公開設定と移植内容 |
|---:|---|
| 0～29 | 非同期、fc=1045 Hz |
| 29～56 | 非同期、(29,1045)→(55.9,700)の直線 |
| 56～67 | 非同期、(56,700)→(67,1600)の直線 |
| 67～73 | 広域3パルス |
| 73以上 | 1パルス矩形波 |

直前の周波数変更が増加なら力行、減少なら減速の設定を保持する。ボタンUP/DOWNとUSBの`f`/`r`から決める。定速保持中も直前の方向を保持する。これは音選択であり、実際の力行/回生トルク制御ではない。

### 振幅と広域3パルス

非同期の生振幅は力行で`1.37471264*f1/65`、減速で`1.4*f1/73`。公開設定どおり1を超える過変調も許す（最大1.4）。0～1へ一律に丸めたり、既存のV/f=f1/100を流用したりしない。

広域3パルスの生振幅mは力行で(60 Hz,0.7)→(68 Hz,1)、減速で(67 Hz,0.7)→(75 Hz,0.85)の直線。通常の正弦波×三角波3パルスとは別の生成器にする。

公開シミュレーターのSYNC3 Alt1の比較をスイッチング角へ展開すると、`a=π/3*(1-m)`。U相のHigh区間を`[a,π-a)`、`[π,π+a)`、`[2π-a,2π)`として、V/Wを120°ずらす。1パルスはa=0の極限（正の半周期がHigh）。PIOの保持時間列へ交点時刻を直接変換するため、別の三角波キャリアはない。ログの`fc=0`はこの意味で、出力が停止したことではない。

この数式の対応を確認した参照実装: [VVVF-Simulator L2.cs](https://github.com/VvvfGeeks/VVVF-Simulator/blob/fb8d0c99e0ccc3708fa3429f71bc9270db460193/VvvfSimulator/Vvvf/Calculation/L2.cs)。本プロジェクトではC#コードを取り込まず、公開設定値と角度表現を用いてCで独立実装した。元シミュレーターの利用条件は[README](https://github.com/VvvfGeeks/VVVF-Simulator/blob/main/README_JPN.md)を参照。

`sync3_reference`はこの広域3パルスには適用しない。通常SPWM専用の補正だからである。

## 東芝PMSMの公開ユーザープリセット

出典: [naoto64/VVVF-Simulator / vvvf_pwm_pattern_presets.json](https://github.com/naoto64/VVVF-Simulator/blob/9335c10a135e383e60dc4a1d1ba22063eee40325/vvvf_pwm_pattern_presets.json)、`ユーザー: 東芝PMSM`。コミット`9335c10a135e383e60dc4a1d1ba22063eee40325`。

重要: このファイルの`vmax`は基本波Hzではなく**速度km/h**。同コミットの[保存設定](https://github.com/naoto64/VVVF-Simulator/blob/9335c10a135e383e60dc4a1d1ba22063eee40325/vvvf_current_settings.json)と[換算処理](https://github.com/naoto64/VVVF-Simulator/blob/9335c10a135e383e60dc4a1d1ba22063eee40325/vvvf_pwm_pattern_gui_nuitka_onefile_path_fixed.py)から、`f1=速度*79.79401993355482/80.12956810631229`とした。したがって35/60/80をそのままHzとして扱わない。

| 元の速度範囲 km/h | 換算した基本波Hz | 対応 |
|---:|---:|---|
| 0～35 | 0～約34.85344 | 非同期fc=750 Hz |
| 35～60 | 約34.85344～59.74875 | 同期9パルス、基本波×9 |
| 60～80 | 約59.74875～79.66499 | 広域3パルス |
| 80以上 | 約79.66499以上 | 1パルス矩形波 |

生振幅は保存設定に合わせて`min(f1/79.79401993355482,1)^0.92`。広域3パルスの角度はこの作者の式`a=38°*(1-m)^0.72`を用いる。JRの式と混同しない。出典のMITライセンスは[third-party/naoto64-MIT.txt](third-party/naoto64-MIT.txt)に収録。

### 今回移植していない部分

- 低速3 km/h未満（基本波約2.98744 Hz未満）の187.5 Hz矩形高周波注入、量25%。これはキャリア周波数の変化ではなく三相指令への重畳なので、750 Hzの変更で代用しない。
- 参照実装の特殊な同期9パルス波形。今回は通常の正弦波・三角波比較による同期9パルスを使うため、周波数対応は同じでもパルスの形と音色まで同一ではない。
- PCシミュレーター固有のモーター・車体共鳴、速度追従スムージング、音量補正。

したがって現在の`pmsm-toshiba`は、公開データに基づく基本波・キャリア対応と基本パルス切り替えの移植。実車PMSMの全音色を再現済みと扱わない。`pmsm-demo`は互換用の別名として残すが、以前の2000～3000 Hzの仮曲線は使わない。

## 実装と再現性

- 数値出典: `Doc/preset-sources.json`（コミット固定）。
- 曲線・角度係数・力行／減速の設定: `src/profiles/presets.c`。共通評価: `src/control/profiles.c`。
- 生振幅、角度への変換: `src/control/control.c`。
- 直接パルスの出力時刻: `src/control/programmed.c`。
- 既存IGBT/GTOの通常SPWMと、そのN=3補正表は変更しない。

ホストテストで周波数境界、方向別曲線、0～110 Hz走査、広域3/1パルスの角度オラクル、フレーム継続時間・バッファ容量を検証する。実機の結果は[公開パターン測定ログ](captures/public-profiles-summary.json)と`captures/jr-fall-power-*` / `jr-fall-brake-*` / `pmsm-toshiba-power-*`を参照。

## 今回の実機測定結果

再接続後、28動作点（JR力行11点、JR減速8点、PMSM9点）を各1秒・2 MHzで取得。CH0=U、CH1=V、CH2=W。全測定点で有効な波形を取得し、`fault=0`、最大`render_max=1197 µs`だった。バッファ長は2560 µs。終了後は`igbt`・0 Hzへ戻した。

| 設定 | 設定キャリア/方式 | 1秒間のU相立ち上がり実測 |
|---|---|---:|
| JR力行5 Hz | 非同期1045 Hz | 1045回 |
| JR力行35 Hz | 非同期約889.788 Hz | 889回 |
| JR力行60 Hz | 広域3パルス | 180回 |
| JR力行65 Hz | 広域3パルス | 195回 |
| JR力行67 Hz | 1パルス | 67回 |
| JR減速70 Hz | 広域3パルス | 210回 |
| PMSM10 Hz | 非同期750 Hz | 750回 |
| PMSM35 Hz | 同期9パルス・315 Hz | 315回 |
| PMSM65 Hz | 広域3パルス | 195回 |
| PMSM100 Hz | 1パルス | 100回 |

過変調ではキャリアの一部の周期に出力エッジがなくなる。例えばJR力行48.9 Hzでは設定fc=710 HzでもU相の立ち上がりは594回だった。エッジ数をそのままキャリア周波数とみなさない。ホストで公開データに対する3321点の評価を照合し、設定値と出力波形の確認を分けている。

代表キャプチャはlibsigrokで再読み込みを確認した。電力段やモーター音を測定したものではない。全境界を連続ランプで往復した過渡波形・長時間耐久・低速HFIは未確認/未実装。
